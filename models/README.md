# Модели Krimson

Обученные модели и подобранные пороги. Папка хранится в git: закоммитьте и запушьте её после обучения,
на другом устройстве сделайте pull — приложение подхватит модели сразу.

```
registry.json                     активная версия для каждой области (откат = выбрать старую версию)
general/params/v001.json          общие пороги — для залов без своих версий
general/ball/v001.pt + .json      общий детектор мяча
venue/<слаг>/venue.json           название зала (зал появится в приложении на другом устройстве)
venue/<слаг>/params/, ball/       пороги и детектор конкретного зала
team/<слаг>/players/v001.pt       узнавание игроков команды
```

Версии не перезаписываются: каждое обучение создаёт v002, v003… с метриками в `.json`.
Управление — страница «Обучение» в приложении или `uv run python -m app.learning ... --scope venue/<слаг>`.

Файлы весов (детектор ≈ 18 МБ на версию, игроки ≈ 3 МБ) хранятся через Git LFS — правило в `.gitattributes`.
На новом устройстве один раз: установить git-lfs (`brew install git-lfs` / `winget install GitHub.GitLFS`),
затем `git lfs install` и `git lfs pull` (обычный `git pull` после этого скачивает веса сам).
