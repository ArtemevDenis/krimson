# Krimson

Локальное приложение для сбора волейбольной статистики по видеозаписям матчей (6×6, система 5-1, либеро).
Статистика ведётся по игрокам своей команды в стиле DataVolley, хайлайты собираются из размеченных розыгрышей.

## Запуск

Нужны: Python 3.12 + [uv](https://docs.astral.sh/uv/), Node 20+, ffmpeg.

```bash
./run.sh   # собрать UI и открыть http://localhost:8000
./dev.sh   # разработка: http://localhost:5173 (hot reload фронта и бэка)
```

Данные (SQLite, прокси-видео, экспорт роликов, веса моделей) лежат в `data/`. Исходные видео не копируются, если подключать их по пути.

Для авторазметки нужны CV-зависимости: `cd backend && uv sync --extra cv` (PyTorch + YOLO; на Windows ставится сборка с CUDA).

## Как размечать

1. **Состав** → импорт списком: `15 Иван Петров доигровщик` (по строке на игрока).
2. **Матчи** → новый матч → «+ Партия» (одна запись = одна партия).
3. В партии: подключить видео (путь к файлу), задать стартовую расстановку, либеро и кто подаёт первым.
4. Смотреть видео и вводить коды в строку под плеером:

| Код | Значение |
|-----|----------|
| `15a#` | игрок 15, атака, очко |
| `s-` | подача подающего (номер не нужен), соперник принял хорошо |
| `7r+ 10e# 15a#` | несколько действий через пробел |
| `[` / `]` | начало / конец розыгрыша по текущему кадру |
| `+` / `-` | очко нам / соперникам (если не следует из кода) |
| `*` | отметить розыгрыш в хайлайты |
| `10e+ 10vn` / `10e+ 10нс` | пас хороший, потом №10 коснулся сетки (нарушение) |
| `vf` / `нл` | заступ при подаче (подающий; считается и ошибкой подачи) |

Нарушения — `v` (violation) или `н` + тип:

| Нарушение | англ. | рус. |
|-----------|-------|------|
| касание сетки | `10vn` | `10нс` |
| заступ за центральную линию | `10vc` | `10нц` |
| двойное касание | `10vd` | `10нд` |
| захват | `10vh` | `10нз` |
| заступ при подаче (без номера — подающий) | `vf` | `нл` |
| четыре касания (команда) | `v4` | `н4` |
| переход / расстановка (команда) | `vr` | `нп` |

Всегда очко сопернику и ошибка игрока; в анализатор не идут.

Элементы: `s` подача, `r` приём, `e` передача, `a` атака, `b` блок, `d` защита, `f` свободный мяч (приняли),
`g` перевод — отдали мяч сопернику без атаки (`7r- 10e- 15g-`; в атаку не идёт, своя колонка в статистике).
Оценки: `# + ! - / =` (как в DataVolley). Русская раскладка работает: `15ф№` = `15a#`.

Счёт, переход, подающий и выход либеро считаются автоматически из исходов розыгрышей,
поэтому исправление любого прошлого розыгрыша пересчитывает всё после него.

Состав (номера, ФИО) вводится один раз; расстановка, **роли игроков**, либеро и первая подача задаются у каждой партии
свои (роль из состава — только подсказка по умолчанию). Замены — «Замена игрока» под схемой площадки,
действуют со следующего розыгрыша:
- **Играет** — по умолчанию вышедший берёт роль заменённого (замена по позиции: либеро так же выходит за него,
  расстановки P1–P6 считаются дальше); можно выбрать другую роль.
- **На подачу** — над счётом появится напоминание «вернуть», когда подача потеряна или запасной дошёл до передней линии.
- **Либеро не выходит** (кнопка над счётом) — центральный остаётся в задней линии, пока не уйдёт вперёд.

Тестовая или лишняя разметка: **«В архив»** у матча — разметка сохраняется, но не входит в статистику сезона
(вернуть можно из раздела «Архив» в списке матчей); **«Очистить разметку»** в партии — удаляет розыгрыши и действия,
видео, площадка и расстановка остаются.

Горячие клавиши: `Tab` — пауза, `Alt+←/→` — ±2 с (`+Shift` — ±10 с), `Backspace` в пустой строке — отмена,
`Esc` — выйти из редактирования прошлого розыгрыша.

## Авторазметка (этап 2)

1. В партии — **Площадка** → «Взять кадр» → 6 кликов: 2 угла нашей задней линии, 2 угла дальней, 2 конца центральной линии.
   Угол за кадром можно поставить в серое поле. Если камеру переставляли — отдельная разметка с момента перестановки.
2. **Авторазметка** — поиск розыгрышей и подсказки действий. Самое долгое — проход нейросети по видео
   (на M1 Pro ≈ 3.5× длины видео, т.е. ~1.5 ч на партию; на RTX 2060S в разы быстрее). Результат кешируется в
   `<видео>.krimson-det.json.gz` рядом с файлом, повторный анализ — секунды.
3. Проверка подсказок: **Enter в пустой строке** — к следующей подсказке (видео останавливается на касании,
   жёлтый круг — мяч, голубая рамка — игрок). Дальше:
   - `31+` — принять: игрок 31, оценка `+`, элемент из подсказки;
   - `31d+` — элемент другой (исправить подсказку);
   - `x` (`ч`) — это не касание нашей команды;
   - Enter — пропустить.
   Найденные розыгрыши помечены «авто»; очко (`+`/`-`) ставится как обычно.

### Тяжёлый расчёт на Windows

```powershell
.\precompute.ps1 D:\volley\VID_20260328_185649.mp4
```

Скопируйте получившийся `VID_20260328_185649.mp4.krimson-det.json.gz` рядом с видео на Mac — приложение возьмёт его
вместо пересчёта. Можно и целиком работать на Windows: `.\run.ps1`.

## Обучение на своих данных

Анализатор доучивается на партиях, которые вы разметили полностью, **отдельно для каждого зала**.

1. У матча укажите **зал** (при создании или в шапке матча). Зал определяет, какими моделями размечается видео.
2. Разметьте партию: все розыгрыши и **все касания нашей команды** (лучше через подсказки — точное время и рамка игрока)
   и нажмите **«Отметить проверенной»**.
3. Страница **«Обучение»** → выберите область:
   - **зал** — свои пороги и свой детектор мяча; обучение здесь не меняет модели других залов;
   - **общая модель** — учится на всех залах, используется в залах без своих версий (и как старт для нового зала);
   - **команда** — узнавание игроков (одни и те же игроки в любом зале).

   В каждой области: **Оценить точность**, **Подобрать пороги** (секунды), **Детектор мяча** (долго, лучше на Windows),
   **Узнавание игроков**. Каждое обучение создаёт новую версию (v001, v002…) с метриками.
4. **Откат**: в списке версий нажмите «сделать активной» у старой версии или «использовать» общую/стандартную модель.

Какая модель применяется к партии: версия зала → общая версия → стандартная модель / пороги по умолчанию.

### Перенос между устройствами

Модели лежат в `models/` в корне проекта и хранятся в git, веса `.pt` — через Git LFS (структура — в `models/README.md`).
На новом устройстве один раз поставьте git-lfs и выполните `git lfs install`.

```bash
git add models && git commit -m "Модели: пороги домашнего зала v002" && git push   # где обучали
git pull                                                                         # на другом устройстве
```

Залы и команды связываются по слагу (`domashniy-zal`), а не по id в базе: зал из `models/` появится в приложении
сам, команду создайте с тем же названием. Обучать можно на Windows — там же `git push`:

```powershell
cd backend
uv run python -m app.learning ball-dataset --scope venue/domashniy-zal
uv run python -m app.learning train-ball --scope venue/domashniy-zal
uv run python -m app.learning train-players --scope team/krimson
```

Детекции для нового детектора: `.\precompute.ps1 --venue domashniy-zal D:\volley\VID_....mp4`.

## Структура

```
backend/app/
  domain/      чистая логика: ротация 5-1 + либеро, оценки DataVolley, статистика, хайлайты
  services/    ffmpeg (прокси 720p/30fps, экспорт роликов), фоновые задачи, сборка состояния партии
  routers/     REST API (/api/...)
  cv/          компьютерное зрение: детекция (YOLO, кеш), треки мяча, розыгрыши, касания → подсказки
  learning/    эталон из проверенных партий, метрики, подбор порогов, датасеты и обучение моделей
  modelstore.py версии моделей в models/ (по залам, общая, по командам), активная версия, откат
models/        обученные модели и пороги — в git
frontend/src/  Preact + Effector + Tailwind, Feature-Sliced: pages / features / shared
```

## Этапы

- **Этап 1 (готов):** ручная разметка с автоматикой счёта/ротаций, статистика игроков и по расстановкам, сезон, хайлайты.
- **Этап 2 (готов, первая версия):** разметка площадки, автопоиск розыгрышей по полёту мяча, касания и тип действия
  по порядку касаний (подача → приём/защита → передача → атака, блок у сетки), режим быстрой проверки подсказок.
- **Дальше:** распознавание номеров игроков (подсказка «кто»), «эмоциональные» моменты по звуку,
  дообучение детектора мяча на подтверждённых вами розыгрышах.
