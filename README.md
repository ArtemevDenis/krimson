# Krimson

Локальное приложение для сбора волейбольной статистики по видеозаписям матчей (6×6, система 5-1, либеро).
Статистика ведётся по игрокам своей команды в стиле DataVolley, хайлайты собираются из размеченных розыгрышей.

## Запуск

Нужны: Python 3.12 + [uv](https://docs.astral.sh/uv/), Node 20+, ffmpeg.

```bash
./run.sh   # собрать UI и открыть http://localhost:8000
./dev.sh   # разработка: http://localhost:5173 (hot reload фронта и бэка)
```

Данные (SQLite, прокси-видео, экспорт роликов) лежат в `data/`. Исходные видео не копируются, если подключать их по пути.

## Как размечать

1. **Состав** → импорт списком: `15 Иван Петров доигровщик` (по строке на игрока).
2. **Матчи** → новый матч → «+ Партия» (одна запись = одна партия).
3. В партии: подключить видео (путь к файлу), задать стартовую расстановку, либеро и кто подаёт первым.
4. Смотреть видео и вводить коды в строку под плеером:

| Код | Значение |
|-----|----------|
| `15a#` | игрок 15, атака, очко |
| `s-` | подача подающего (номер не нужен), соперник принял хорошо |
| `7r+ 10e# 15a#` | несколько действий через пробел |
| `[` / `]` | начало / конец розыгрыша по текущему кадру |
| `+` / `-` | очко нам / соперникам (если не следует из кода) |
| `*` | отметить розыгрыш в хайлайты |

Элементы: `s` подача, `r` приём, `e` передача, `a` атака, `b` блок, `d` защита, `f` свободный мяч.
Оценки: `# + ! - / =` (как в DataVolley). Русская раскладка работает: `15ф№` = `15a#`.

Счёт, переход, подающий и выход либеро считаются автоматически из исходов розыгрышей,
поэтому исправление любого прошлого розыгрыша пересчитывает всё после него.

Горячие клавиши: `Tab` — пауза, `Alt+←/→` — ±2 с (`+Shift` — ±10 с), `Backspace` в пустой строке — отмена,
`Esc` — выйти из редактирования прошлого розыгрыша.

## Структура

```
backend/app/
  domain/      чистая логика: ротация 5-1 + либеро, оценки DataVolley, статистика, хайлайты
  services/    ffmpeg (прокси 720p/30fps, экспорт роликов), фоновые задачи, сборка состояния партии
  routers/     REST API (/api/...)
  cv/          каркас компьютерного зрения: протоколы детекторов (этап 2–3)
frontend/src/  Preact + Effector + Tailwind, Feature-Sliced: pages / features / shared
```

## Этапы

- **Этап 1 (готов):** ручная разметка с автоматикой счёта/ротаций, статистика игроков и по расстановкам, сезон, хайлайты.
- **Этап 2:** `cv/detectors/` — автопоиск розыгрышей (трекинг мяча + движение игроков + звук), «эмоциональные» моменты.
  Кнопка «Автопоиск розыгрышей» уже вызывает детектор через очередь задач; сейчас подключена заглушка.
- **Этап 3:** трекинг игроков и распознавание номеров → подсказки «кто атаковал/принимал».
